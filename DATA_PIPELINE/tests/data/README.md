`openear_zeta_ossicles.npz`: the ossicles, tympanic membrane, scalae and neighbouring labels
of OpenEar specimen ZETA, bit-packed (see `DATA_PIPELINE/extract_dev.py`). From Sieber et al.,
The OpenEar library of 3D models of the human temporal bone based on computed tomography and
micro-slicing, Scientific Data 6, 180297 (2019), doi:10.1038/sdata.2018.297; data
doi:10.5281/zenodo.1473724. CC BY 4.0. Used as a regression fixture for `otopipe/ossicles.py`.
